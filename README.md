# Clawd: When Intelligence Grew Hands

A 10-minute presentation on the shift from AI-as-chatbot to AI-as-agent — what changed, what breaks, and why human judgment still matters.

**By Otto von Wachter**

## What's in here

| File | What it is |
|------|-----------|
| `pres.html` | Reveal.js slide deck (12 slides, keyboard-driven) |
| `pres-audio.html` | Same deck with auto-narrated audio playback |
| `script.html` | Full speaker script, mobile-friendly for rehearsal |
| `cues.html` | Keyword cue cards for quick glance while presenting |
| `index.html` | Landing page linking everything together |
| `clawd-presentation.zip` | Offline bundle (2.1 MB) — unzip and open `pres.html` |

## Running locally

Open `index.html` in a browser. Everything is self-contained — no build step, no server required.

All vendor dependencies (Reveal.js, Lucide icons, Manrope font) are bundled in `vendor/`.

## Keyboard shortcuts (in presentation)

- **S** — speaker notes
- **F** — fullscreen
- **T** — cycle background styles
- **Space / Arrow keys** — navigate slides

## Talk structure

1. **Title** — "When Intelligence Grew Hands"
2. **The Elephant** — name the fears in the room
3. **The Shift** — from question→answer to goal→act→observe→adjust
4. **The Pace** — chatbots (2023) → code agents (2025) → autonomous actors (2026)
5. **Hands** — create, use tools, connect to systems
6. **The Loop** — one-shot vs. agentic architecture
7. **A Simple Task** — the tax form story (confident + wrong)
8. **Drift** — when plausible output replaces real progress
9. **The Conviction** — AI revealed what the work actually was
10. **Judgment** — the bottleneck shifted from execution to judgment
11. **Trust** — scope, visibility, reversibility
12. **Close** — "Don't let it drift"
