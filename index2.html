What I mean by "hands"

write / edit — docs, code, messages

browse / research — read the web, find sources

run tools — scripts, terminals, workflows

call APIs — software talking to software

loop — try, observe, adjust, repeat

Technical grounding after the emotional opening. "Hands means tool access plus loops, not just better prose." This slide should feel like relief — "oh, that's how it works."

The architecture of doing

Walk the loop once: goal, context, plan, act, observe, evaluate. "This is the heartbeat. Not one prompt. A loop of intention, action, and feedback." "This is how you work on a hard problem. Now machines work this way too."

Four beats: task, before, after, delta. "The agent did 90 minutes of assembly. I spent 12 minutes on judgment." "And those 12 minutes were the only part that actually needed me." Guardrails: agent can't send anything — I approve every external action.

Why AGI debates feel stuck

Intelligence — can it reason?

Capability — what can it do?

Agency — can it act in the world?

Autonomy — does it act without asking?

Reliability — can we trust the results?

One word. Five different questions. That's why nobody agrees.

Run through each quickly. Land the punchline: "A brain in a jar: high intelligence, zero agency. A Roomba: high agency, mediocre intelligence. The interesting zone is where they overlap. That's where we are now."

The real threshold is trust

"Is it smart?" — interesting but insufficient

"Can I trust it?" — the question that actually matters

Scope

what it's allowed to do

Visibility

what it did and why

Reversibility

can we undo mistakes fast

"This is the same framework you already use — for employees, contractors, babysitters." "The delegate is new. The delegation logic is ancient." Make it practical: scope, visibility, reversibility.
